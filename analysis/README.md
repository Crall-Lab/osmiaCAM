# codeSupplement

Code supplement for the osmiaCAM system. 

# Written by James Crall with GPT 5.3 Codex 

## What is included
This folder contains code and example data for the foraging activity analysis of 'OsmiaCAM: a low-cost, open source, automated monitoring system for solitary bees', including annotation and tracking scripts, sample videos, and data output and code used to generate figures in the main text.


### 1) Main scripts (`scripts/`)

- `bee_roi_tracker.py`: main ROI transit detector.
- `annotate_daily_rois.py`: day-by-day ROI annotation workflow.
- `validate_rois_one_frame_per_day.py`: one-frame ROI overlay checks.
- `make_transit_validation_gifs.py`: per-day transit GIF generation for validation.
- `make_transit_validation_gifs_pooled.py`: pooled multi-day GIF generation for validation.
- `analyze_osmia4_events_weather.R`: analysis + figure generation for manuscript outputs.
- `nestcam_generate_scaled_frames.py`: generates `_scaled` median-frame nest images from `.h264` clips.
- `nestcam_make_timelapse.py`: builds timestamped nest timelapse videos from `_scaled` images.

Convenience wrappers:

- `run_example_tracking.sh`
- `run_example_gif_validation.sh`
- `run_manuscript_figures.sh`
- `run_nestcam_timelapse_example.sh`

### 2) Small runnable example dataset (`example_data/`)

- `videos/04_04_25/` includes 2 raw videos (`.h264`).
- `rois/04_04_25/` includes matching `rois.json` and `roi_validation_overlay.jpg`.
- `output/04_04_25/` is the example run/output area created by the helper scripts.
- `reference_outputs/04_04_25/` contains subset `events`/`summary` CSVs for quick output checks.

### 3) Validation GIF outputs

- Manuscript validation GIF set: `manuscript/validation_gifs/` (full set used for manuscript validation).
- Example GIF outputs from the 2-video example run:
  - `example_data/output/04_04_25/batch_runs/transit_gif_validation_generated/` (generated by script)
  - `example_data/output/04_04_25/batch_runs/transit_gif_validation_examples/` (packaged sample reference GIFs)

### 4) Manuscript outputs + figure-generation inputs (`manuscript/`)

- `figures/` contains manuscript figure PDFs:
  - `osmia4_events_time_vs_roi_in_out.pdf` (Fig2)
  - `osmia4_transits_2h_violin_by_roi.pdf` (Fig3A)
  - `osmia4_transits_vs_temp_2h.pdf` (Fig3B)
  - `osmia4_cells_vs_mean_foraging_2h.pdf` (Fig3C)
  - `osmia4_transits_by_time_2h_by_roi.pdf` (FigS1)
- `analysis_tables/` contains key output tables/CSVs used in the manuscript analysis.
- `source_data/events_by_day/` contains per-day `events.csv` and `summary.csv` used to regenerate manuscript figures.
- `source_data/weather_logs/` contains weather logs used by the R analysis script.

## Run from scratch on the example videos

From repository root:

```bash
cd codeSupplement
bash scripts/run_example_tracking.sh
```

Expected outputs:

- `example_data/output/04_04_25/analysis_output/roi_trial_full_v1_with_video/events.csv`
- `example_data/output/04_04_25/analysis_output/roi_trial_full_v1_with_video/summary.csv`
- annotated videos (`*_annotated.mp4`) in the same output folder

Optional quick comparison with packaged references:

```bash
wc -l example_data/reference_outputs/04_04_25/events_example_subset.csv
wc -l example_data/output/04_04_25/analysis_output/roi_trial_full_v1_with_video/events.csv
```

## Nest Camera Timelapse

One-command example (uses `../nestCam/04_04_25` and writes outputs to `example_data/nestcam_output/04_04_25`):

```bash
cd codeSupplement
bash scripts/run_nestcam_timelapse_example.sh
```

Manual two-step usage:

```bash
cd codeSupplement
python3 scripts/nestcam_generate_scaled_frames.py ../nestCam/04_04_25 --output-root example_data/nestcam_output --output-format png --norm percentile --percentiles 1,99 --crop-top 225
python3 scripts/nestcam_make_timelapse.py example_data/nestcam_output/04_04_25 --codec h264_qt --fps 10 --output-name timelapse_qt.mp4
```

Expected outputs (example run):

- `example_data/nestcam_output/04_04_25/*_scaled.png`
- `example_data/nestcam_output/04_04_25/timelapse_qt.mp4`
- `example_data/nestcam_output/04_04_25/timelapse_qt.csv`
